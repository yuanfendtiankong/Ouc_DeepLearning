## 运行方式

准备好 Python 和 Jupyter Notebook 环境后，在项目根目录启动：

    jupyter notebook

然后打开 first_class 下对应练习目录中的 Notebook，按单元格顺序运行。各次练习所需的 Python 包请根据 Notebook 中的导入语句安装。
